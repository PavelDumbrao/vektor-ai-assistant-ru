# Вектор — ваш личный ИИ-ассистент в Telegram

Это готовый персональный ассистент, который живёт у вас в Telegram и работает **на вашем компьютере или сервере** — переписка и файлы остаются у вас.

**Что он умеет сразу после установки:**

- 📄 Делает документы по одной фразе: «сделай приказ о…», «подготовь коммерческое предложение…» — и присылает готовый файл Word или PDF прямо в чат
- 🎙 Понимает голосовые: наговорили задачу на ходу — он расшифровал и сделал
- ⏰ Напоминания: «напомни завтра в 10 позвонить поставщику» — напомнит
- 🧠 Помнит контекст: договорённости, задачи, о чём говорили
- 🗣 Может отвечать голосом
- 🔌 Подключает Google Drive, Gmail, Notion, Slack и другие сервисы через личный Maton — ключ вводится защищённой командой в Telegram
- 🔎 (продвинутое) Видит вашу рабочую переписку и отвечает на вопросы «что было с Ивановым?», «подведи итоги недели»

Никакого программирования не нужно: устанавливает всё **ваш ИИ-агент** (Claude Code, Codex или аналог) — вы только даёте ему этот репозиторий и две «бумажки».

## Что понадобится

1. **Telegram** — у вас он уже есть.
2. **ИИ-агент на компьютере** — Claude Code или Codex. Нет ни одного? Поставить — 5 минут: [docs/00-install-agent.md](docs/00-install-agent.md). На Windows понадобится WSL (подсистема Linux) — в той же инструкции.
   Подписка не обязательна: агент может работать и по клубному API-ключу.
3. **15–20 минут.**

## Установка за 4 шага

### Шаг 1. Создайте своего телеграм-бота (3 минуты)

По инструкции [docs/01-telegram-bot.md](docs/01-telegram-bot.md) — там буквально «нажмите это, напишите то». На выходе у вас будет **токен бота** — длинная строка вида `1234567890:AA...`. Сохраните её.

### Шаг 2. Выберите «мозг» ассистента (2 минуты)

Ассистенту нужна нейросеть. Три варианта — подробно в [docs/02-llm-provider.md](docs/02-llm-provider.md):

| Вариант | Что нужно |
|---|---|
| Подписка Claude | только план **Max** — используем её |
| Подписка ChatGPT | уже платите за ChatGPT — используем её |
| API-ключ | нет подписок? Ученикам клуба Павел выдаёт клубный ключ — просто вставите его |

### Шаг 3. Отдайте репозиторий своему агенту (он сделает всё сам)

Откройте Claude Code (или Codex) в пустой папке и отправьте ему сообщение:

```text
Склонируй репозиторий https://github.com/PavelDumbrao/vektor-ai-assistant-ru и установи мне из него личного ИИ-ассистента «Вектор» строго по инструкции AGENTS.md (сценарий A — на этом компьютере). Делай всё сам, я новичок: не отправляй меня в терминал, объясняй по-русски и простыми словами. Если чего-то не хватает — задавай мне вопросы по одному.

Мои данные:
— токен телеграм-бота от BotFather: ВСТАВЬТЕ_ТОКЕН_ИЗ_ШАГА_1
— мой Telegram ID: ВСТАВЬТЕ_ID (если не знаете — агент подскажет, как узнать)
— «мозг»: ВЫБЕРИТЕ ОДНО → «подписка Claude (план Max)» / «подписка ChatGPT» / «API-ключ: вот ключ, адрес сервера и модель, которые мне выдали: ...»

Когда закончишь — прогони проверку из AGENTS.md (документ Word вложением, напоминание через 3 минуты, голосовое) и скажи мне, что именно написать боту, чтобы убедиться, что всё работает.
```

Агент сам поставит зависимости, разложит файлы, всё настроит и скажет, когда готово. Если он что-то спросит — отвечайте простыми словами, он разберётся.

### Шаг 4. Проверьте

Напишите своему боту в Telegram:

1. «Привет! Что ты умеешь?»
2. «Сделай служебную записку о покупке принтера, пришли файлом Word» — придёт настоящий файл
3. «Напомни через 3 минуты: проверка» — через 3 минуты придёт напоминание
4. `/maton` — бот предложит безопасно добавить личный ключ Maton и затем подключать нужные сервисы

Работает? Поздравляем, у вас личный ИИ-ассистент. 🎉

## Дальше

- **Работа 24/7.** Пока компьютер спит — бот молчит. Хотите, чтобы работал всегда — арендуйте сервер за ~500–1000 ₽/мес и попросите агента переехать: [docs/03-server.md](docs/03-server.md) (Hostinger и Timeweb, по шагам).
- **Архив переписки** («что было с Ивановым?»). Нужны Telegram Premium и сервер: [docs/04-passive-secretary.md](docs/04-passive-secretary.md).
- **Google Drive, Gmail, Notion и другие сервисы.** Подключаются через личный Maton прямо в Telegram: [docs/06-maton.md](docs/06-maton.md).
- **Характер ассистента.** Напишите своему агенту: «открой мой SOUL.md и помоги заполнить раздел „Кто твой владелец“» — чем точнее, тем полезнее ответы.
- **Что-то не работает** — [docs/05-troubleshooting.md](docs/05-troubleshooting.md), там ответы на типовые проблемы.

## Безопасность — три правила

1. **Токен бота и API-ключи никому не показывайте** и никуда не выкладывайте. Ключ Maton передавайте только после команды `/maton`: следующее сообщение удаляется до LLM и логов. Никогда не вставляйте его в обычный диалог.
2. В настройке уже включена защита: боту можете писать **только вы** (ваш Telegram ID в allowlist).
3. Ассистент **сам никому не пишет** от вашего имени и не подписывает документы — это принцип.
