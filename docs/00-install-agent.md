# Как установить ИИ-агента (Claude Code или Codex) — 5 минут

Агент — это программа, которая установит вам ассистента и дальше будет помогать со всем техническим. Ставим один из двух: **Claude Code** (от Anthropic) или **Codex** (от OpenAI). Любой подойдёт.

> Подписка не обязательна: Claude Code умеет работать по API-ключу — если вы в клубе, Павел выдаст клубный ключ.

## Если у вас Mac

1. Откройте программу **Терминал** (лупа 🔍 в правом верхнем углу → наберите «Терминал» → Enter). Это окно, куда печатают команды — не бойтесь его.
2. Скопируйте туда одну строку и нажмите Enter:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

3. Когда установка закончится, закройте и снова откройте Терминал, наберите `claude` и нажмите Enter.
4. Программа предложит войти: через подписку Claude или по API-ключу — выберите своё и следуйте подсказкам на экране.

## Если у вас Windows

Понадобится WSL — «подсистема Linux» внутри Windows (стандартная функция, ставится одной командой):

1. Нажмите **Пуск**, наберите **PowerShell**, запустите **от имени администратора** (правой кнопкой).
2. Введите: `wsl --install` и нажмите Enter. Дождитесь окончания и **перезагрузите компьютер**.
3. После перезагрузки откроется чёрное окно Ubuntu — придумайте там имя пользователя и пароль (пароль при вводе не отображается — это нормально).
4. В этом же окне Ubuntu выполните строку из инструкции для Mac (пункт 2) и дальше по ней же.

## Если хотите Codex (вместо Claude Code)

В терминале (Mac) или окне Ubuntu (Windows):

```bash
npm install -g @openai/codex
```

(если скажет, что нет `npm` — сначала поставьте Node.js с nodejs.org, кнопка LTS). Затем наберите `codex` и войдите в аккаунт ChatGPT по подсказкам.

## Проверка

Наберите `claude` (или `codex`) — открылся чат с агентом прямо в терминале? Готово. Возвращайтесь в [README](../README.md), шаг 3: там готовая фраза, которую нужно отправить агенту.
