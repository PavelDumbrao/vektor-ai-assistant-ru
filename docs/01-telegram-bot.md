# Как создать своего телеграм-бота (3 минуты, без программирования)

Бот — это «оболочка» вашего ассистента в Telegram. Создаётся у официального бота Telegram по имени BotFather.

## Шаги

1. Откройте Telegram и в поиске наберите **@BotFather** (синяя галочка — это официальный бот Telegram).
2. Нажмите **Запустить** (или напишите `/start`).
3. Напишите команду: `/newbot`
4. BotFather спросит **имя** бота — это то, что видно в шапке чата. Напишите, например: `Вектор` (или как хотите — «Мой ассистент», ваше имя…).
5. BotFather спросит **username** — это адрес бота, латиницей, обязательно заканчивается на `bot`. Например: `ivan_vektor_bot`. Если занято — попробуйте другой вариант.
6. Готово! BotFather пришлёт сообщение с **токеном** — длинной строкой вида:
   `1234567890:AAEhBOweik6ad9r_QXMENQjcrGbqCr5yPY8`

## Что сделать с токеном

- **Скопируйте и сохраните** — он понадобится агенту-установщику на шаге 3 из README.
- **Никому не показывайте** (кроме своего агента-установщика — ему он нужен для настройки). Токен = полный доступ к боту. Если случайно засветили — в BotFather: `/mybots` → ваш бот → API Token → Revoke (выдаст новый).

## Две настройки (по желанию, потом)

- Аватарка: `/mybots` → ваш бот → Edit Bot → Edit Botpic — пришлите картинку.
- Описание: Edit Bot → Edit Description.

## Узнать свой Telegram ID (агент попросит)

Напишите боту **@userinfobot** любое сообщение — он ответит вашим ID (число вроде `123456789`). Этот ID нужен, чтобы вашему ассистенту могли писать только вы.
