# Переезд на сервер: ассистент работает 24/7

На своём компьютере бот работает, пока компьютер не спит. Сервер — это компьютер в дата-центре, который не выключается никогда. Стоимость — от ~500 до ~1000 ₽/мес.

## Какой сервер брать

Минимум: **Ubuntu 22.04 или 24.04, 2 ГБ RAM, 40 ГБ диск**. Комфортно: 4 ГБ RAM (нужно для архива переписки и голосовых).

### Вариант 1: Hostinger (hostinger.com)

1. Зарегистрируйтесь → раздел **VPS** → выберите план KVM 1 (2 ГБ) или KVM 2 (4 ГБ).
2. Операционная система: **Ubuntu 24.04** (чистая, без панелей).
3. При создании сервер попросит **root-пароль** — придумайте и сохраните.
4. После оплаты в панели появится **IP-адрес** сервера. Сохраните: IP + root-пароль.

### Вариант 2: Timeweb Cloud (timeweb.cloud)

1. Регистрация → **Облачные серверы** → Создать сервер.
2. ОС: **Ubuntu 24.04**. Конфигурация: 2 CPU / 2–4 ГБ RAM.
3. Пароль root придёт на почту или задаётся при создании. Сохраните IP + пароль.

**Оплата:** Timeweb Cloud принимает карты РФ. Hostinger — только иностранная карта или оплата через реселлеров; если у вас только российская карта — берите Timeweb.

## Что дальше — отдайте агенту

Откройте своего агента (Claude Code/Codex) и напишите:

```text
Перенеси моего ассистента Вектор на сервер. IP: <адрес>, пользователь root, пароль: <пароль>. Действуй по AGENTS.md, сценарий B.
```

Агент сам подключится, всё установит и запустит как службу (переживает перезагрузки сервера). После переезда бот отвечает даже когда ваш компьютер выключен.

## Безопасность

- Пароль от сервера — как пароль от банка: никому, кроме своего агента.
- Попросите агента после установки настроить вход по SSH-ключу и отключить вход по паролю — это стандартная практика, он знает как.
