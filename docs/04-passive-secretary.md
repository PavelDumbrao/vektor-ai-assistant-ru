# Пассивный секретарь: ассистент видит вашу переписку

Самая мощная функция. После подключения ассистент отвечает на вопросы:

- «Что было в последней переписке с Ивановым?»
- «Подведи итоги дня / недели»
- «Какие задачи и обещания висят?»
- расшифровывает голосовые и кружки из вашей переписки автоматически.

При этом он **только слушает**: сам никому не отвечает и не пишет.

## Что нужно

1. **Telegram Premium** — без него Telegram не даёт раздел «Telegram для бизнеса», через который работает функция.
2. **Сервер** (см. [03-server.md](03-server.md)) — архив хранится в базе данных на вашем сервере, у вас.
3. 10 минут.

## Как подключить

### Часть 1 — делает агент

Напишите своему агенту:

```text
Подключи мне пассивного секретаря (архив переписки) по AGENTS.md, раздел «Пассивный секретарь». У меня есть Telegram Premium и сервер. Мой Telegram ID: ВСТАВЬТЕ_ID.

Когда дойдёт до шага «руками в Telegram» — объясни мне его пошагово и дождись, пока я сделаю. Помоги выбрать разрешённые чаты и исключения. Для архива дополнительные права действий не нужны, но их наличие не должно останавливать сбор.
```

Он поставит базу данных и модуль, активирует и скажет «готово, дальше два шага руками».

### Часть 2 — делаете вы (2 минуты, в вашем Telegram)

1. Откройте **Настройки → Telegram для бизнеса** (раздел есть только с Premium).
2. Выберите **Чат-боты**.
3. В поле впишите username **вашего** бота (например `ivan_vektor_bot`) и выберите его.
4. Выберите, какие чаты бот видит: обычно «Все чаты» + добавьте в исключения те, что показывать не хотите. Это ваш выбор, менять можно в любой момент.
5. Для пассивного архива дополнительные разрешения не нужны: оставляйте ненужные выключенными. Если какое-то право уже включено, например просмотр подарков, **архив продолжает работать**. Разрешение Telegram само по себе не включает отправку, удаление сообщений или другие действия ассистента.

Сбор зависит от активности подключения и выбранных вами чатов, а не от набора
прав действий. Право `can_read_messages` означает возможность отмечать сообщения
прочитанными, а не разрешение получать их для архива:
[документация Telegram](https://core.telegram.org/bots/api#businessbotrights).

### Проверка

Напишите кому-нибудь пару сообщений, подождите минуту и спросите бота: «Что было в моей переписке за сегодня?» Должен ответить по делу и показать, что видел.

Архив начинает собираться после подключения Telegram Business. Импорт старой
истории (`history_backfill`) и обработка media, записанных до включения worker
(`legacy_media_seed`), не входят в ученический релиз и не нужны для штатной
установки нового архива.

## Опционально: ответы от имени вашего Telegram Business

По умолчанию «Вектор» только читает архив и никому не пишет. Ответы включаются
отдельно вашим агентом по разделу «Опциональные ответы от имени Telegram
Business» в `AGENTS.md`.

После включения режима разрешите боту «Ответы на сообщения». Telegram Desktop
может автоматически оставить включённым и «Чтение сообщений» — комбинация 2/5
допустима. «Вектор» принимает неизбежно выданное право, но не вызывает
`readBusinessMessage` и не ставит отметки о прочтении. Все остальные права
должны остаться выключенными для исходящего ответа по текущей политике модуля.
Если набор прав для ответа не подходит, блокируется ответ, но не входящий архив.

Чтобы отправить один ответ, напишите «Вектору» в личный управляющий чат:

```text
ОТВЕТИТЬ: Алексею — «Добрый день! Вернусь с ответом завтра»
```

или:

```text
ОТПРАВИТЬ: Алексею — «Спасибо, документы получил»
```

Затем проверьте получателя и точный текст и нажмите «Отправить один раз».
Работает только для личного Business-чата, где есть входящее сообщение не
старше 24 часов.

Периодические, отложенные и автоматические исходящие сообщения от личного
Telegram Business-профиля сейчас не поддерживаются. Обычные напоминания самому
владельцу через его бот — отдельная функция Hermes и не являются Business-
рассылкой клиентам.

## Приватность — честно

- Архив лежит **на вашем сервере**, в вашей базе. Ни Павел, ни кто-либо ещё доступа не имеет.
- Тексты из переписки уходят только вашему LLM-провайдеру (как любой запрос к нейросети).
- Отключить можно в любой момент: Настройки → Telegram для бизнеса → Чат-боты → удалить бота.
