# Maton: подключение сервисов прямо в Telegram

Maton даёт Вектору доступ к Google Drive, Gmail, Notion, Slack и другим
сервисам через единый MCP. У каждого ученика должен быть собственный аккаунт и
собственный API key Maton.

## Что уже установлено

Вектор поставляется с включённым plugin `maton-onboarding`. Сам Maton MCP до
получения валидного ключа сетево выключен — поэтому новый бот продолжает
нормально работать и не получает ошибки авторизации.

## Как добавить ключ

1. В Maton откройте **Settings** и скопируйте API key.
2. В личном чате со своим Вектором отправьте `/maton`.
3. Бот попросит прислать ключ следующим отдельным сообщением.
4. Сообщение с ключом перехватывается до LLM, сессии и логов. Бот сначала
   удаляет его из Telegram, затем проверяет Maton.
5. Валидный ключ сохраняется в локальном `.env` с правами `0600`, после чего
   Maton MCP включается и перезагружается.

Если Telegram не дал удалить сообщение, ключ не сохраняется. Удалите сообщение
вручную и повторите `/maton`. Не вставляйте ключ в обычный диалог.

## Как подключить сервис

Напишите обычным языком:

> Подключи Google Drive.

Вектор найдёт точное приложение в Maton, вызовет `create_connection` и пришлёт
ссылку авторизации. Откройте её и завершите вход. После этого попросите:

> Проверь, подключился ли Google Drive.

Вектор вызывает `get_connection`. Подключение считается готовым только при
статусе `ACTIVE`; `PENDING` означает, что авторизация ещё не закончена.

## Безопасность

- ключ не передаётся модели и не сохраняется в transcript Hermes;
- сообщение с ключом удаляется до проверки и записи;
- ключ хранится только в личном `HERMES_HOME/.env`;
- подключение одного сервиса не разрешает действия в другом;
- создание подключения не означает разрешение писать, удалять или менять
  данные: для каждого действия нужно отдельное поручение владельца;
- при случайной публикации ключа немедленно отзовите его в Maton → Settings.
