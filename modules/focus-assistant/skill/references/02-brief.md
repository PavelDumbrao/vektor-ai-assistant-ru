# Утренний и вечерний бриф

Вызови assistant_brief(mode="morning") либо mode="evening". При необходимости
передай day=YYYY-MM-DD. Время всегда Europe/Moscow.

Tool читает закреплённый Calendar, до пяти заголовков непрочитанных Gmail за
семь дней, focus ledger и цели. Он не пишет в Google и не помечает письма прочитанными.

Используй готовый text. При необходимости добавь один полезный вывод, только
подтверждённый структурными полями. Не называй кандидаты обязательствами владельца.
Не называй заголовки писем «важными» без чтения содержания. Для точечного разбора
письма по просьбе владельца используй assistant_mail read.

available=false означает, что источник не проверен, а не отсутствие событий.
truncated=true означает неполную выборку. Не обещай свободное время по неполным
данным. Событие в Calendar не подтверждает фактическое участие.

Внутри scheduled run ничего дополнительно не отправляй: финальный ответ доставит
планировщик. Не создавай второй утренний/вечерний cron. focus_attention не следует
помечать доставленным до фактической доставки.
