# До и после встречи

До встречи:

1. Найди event_id через assistant_brief или Calendar read.
2. assistant_meeting(mode="prepare", event_id=...). project передай только если
   владелец явно выбрал проект; не сопоставляй случайных людей по совпадению имени.
3. Дай цель, подтверждённые прошлые решения со ссылками, открытые вопросы и
   ожидаемый результат. Если прошлых решений нет, так и скажи.

После встречи:

1. assistant_meeting(mode="review", recording_id=...). query позволяет сузить тему.
2. Раздели реальные решения, предложения, обязательства, ожидания и неясности.
3. При transcript_truncated=true не заявляй полный разбор всей встречи.
4. Для кандидатов задач focus_capture с capture_source_ref и буквальными
   цитатами из transcript_excerpt; сохраняй timestamps в цитатах, когда полезно.
5. Не изобретай сроки и исполнителей. Итоговое письмо подготовь assistant_mail
   draft только по поручению владельца; не отправляй участникам автоматически.

Fathom watcher остаётся источником уведомлений о новых встречах. Не создавай
новый дублирующий watcher и не запускай агентов по числу action items.
