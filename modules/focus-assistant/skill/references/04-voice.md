# Голосовое → поручения

Используй штатную расшифровку входящего голосового Hermes. Не отправляй тот же
аудиофайл другому провайдеру и не запускай STT второй раз без причины.

Формат Hermes 0.21: успешная расшифровка идёт **в начале текущего пользовательского
сообщения обычным текстом в двойных кавычках**, затем пустая строка и caption.
Отдельного поля `transcript` или метки STT может не быть. Отсутствие такого поля
не означает отсутствие расшифровки. Если этот текст присутствует, извлеки из него
цитату и вызови assistant_voice_intake; не отвечай «STT не пришёл» без проверки.
Реальную ошибку распознавания отличай по явному сообщению gateway про невозможность
распознать/пустую запись. Тогда уточни у владельца, не придумывая содержание.

Раздели сказанное на задачи, обещания, ожидания и идеи. Вызови
assistant_voice_intake с items по схеме focus_capture. Цитаты берутся из текущей
расшифровки; нельзя выдавать исправленное по догадке имя за точную цитату.

Если сомневаешься в имени, отрицании, дате, времени или числе, передай ambiguities.
Tool вернёт один вопрос и ничего не сохранит. «Завтра в 7» требует уточнения
утро/вечер, если контекст не даёт однозначного времени.

После записи покажи короткий список кандидатов, не весь transcript. Не объявляй
задачи выполненными. Для smoke используй dry_run=true и явно помеченный тестовый
текст; тест не должен создавать настоящие напоминания или письма.
