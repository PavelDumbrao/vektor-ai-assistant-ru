# Еженедельный разбор

Вызови assistant_weekly. day опционально задаёт последний день обзорного периода.
Tool разделяет подтверждённо закрытые дела, активные, ожидания и кандидаты, читает
цели/карточки проектов и Calendar за обзорную и следующую недели.

Используй готовый text, дополняя только выводами с понятным источником. Календарная
встреча не равна состоявшейся, candidate не равен обещанию владельца, отсутствие
подтверждённых целей не даёт права придумать их.

Предложи не больше трёх результатов следующей недели. Не меняй task state, дату,
Calendar или project memory в scheduled run. Один конкретный вопрос в конце.

Недельный разбор включается в существующее воскресное вечернее задание в 20:30
МСК. Не создавай второе воскресное сообщение или новую цепочку агентов. Результат
предыдущего run допустим для continuity, но не является свежим источником фактов.
