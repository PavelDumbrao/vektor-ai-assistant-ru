05 / SECURITY

СЕКРЕТЫ ОСТАЮТСЯ СЕКРЕТАМИ

Архитектура Forge разделяет публичный интерфейс, root-операции и runtime каждого AI-сотрудника.

01

Tenant isolation

Каждый новый Hermes получает отдельный Linux tenant и собственный runtime-контур.

02

Write-only secrets

Подключаемые секреты принимаются без возможности прочитать сохранённое значение обратно.

03

Privacy-safe telemetry

Центральная аналитика не принимает тексты сообщений, промпты, ответы модели или аргументы инструментов.

04

Bounded control

Публичный API не выполняет произвольные shell-команды и отделён от root control daemon.
