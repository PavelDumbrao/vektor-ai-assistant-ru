# ВЕКТОР Live

Локальный голосовой ассистент на Mac: вы говорите, он отвечает голосом, видит выбранный вами экран
и обращается к вашему Гермесу за личным контекстом и поручениями.

Всё работает на этом компьютере. Ключи хранятся только здесь и во фронтенд не попадают.

## Как запустить

Дважды кликните **`Start Vektor Live.command`**. Откроется Терминал и окно в Chrome.

1. Нажмите **«Начать разговор»** и разрешите доступ к микрофону.
2. Говорите. Перебивать можно: ассистент замолкает и слушает.
3. Кнопка **«Показать экран»** — выберите монитор, окно или вкладку. Кадры уходят раз в секунду.
4. **«Остановить показ»** — ассистент перестаёт видеть экран и больше не описывает его как текущий.
5. **«Завершить»** или закрытие окна Терминала останавливает всё.

Микрофон работает и без показа экрана. Разрешения запрашивает сам браузер, обойти их нельзя.

## Что куда уходит

- Голос и кадры разрешённого вами экрана отправляются в Google (Gemini Live API).
- Личный контекст и поручения выполняет ваш Гермес — **только после нажатия «Передать Гермесу»**.
  Карточка показывает точный текст, который уйдёт. Без нажатия ничего не отправляется.
- Обычный разговор в Гермес не пишется и его память не меняет.

## Настройки

Файл `.env` (см. `.env.example`). Ключи лежат отдельно, в `~/.claude/secrets/`:
`gemini.env` (ключ Google) и `vektor-live.env` (ключ Гермеса).

| Переменная | Значение по умолчанию | Что делает |
|---|---|---|
| `GEMINI_LIVE_MODEL` | `gemini-3.1-flash-live-preview` | голосовая модель |
| `GEMINI_VOICE` | `Charon` | голос: Charon, Puck, Kore, Fenrir, Aoede, Leda, Orus, Zephyr и другие |
| `VEKTOR_PORT` | `8765` | порт локального сервиса |
| `VEKTOR_IDLE_TIMEOUT` | `900` | закрыть сессию после простоя, секунд |
| `HERMES_BASE_URL` | `http://127.0.0.1:8642` | адрес API Гермеса |
| `HERMES_CONVERSATION` | `vektor-live` | отдельная ветка диалога в Гермесе |

## Гермес

Гермес работает на VPS. Запускалка сама поднимает SSH-туннель к порту 8642, если он не открыт.
Публичный порт наружу не открывается. Состояние связи видно в панели «Состояние».

Если Гермес недоступен, разговор и работа с экраном продолжаются — недоступен только личный контекст.

## Устройство

```
Chrome (микрофон, экран, динамики)
   ↕ WebSocket на 127.0.0.1, токен запуска
app/server.py — мост
   ↕ Gemini Live API (голос и зрение)
   ↕ HTTP → Гермес (личный контекст и поручения)
```

- `app/config.py` — настройки и загрузка секретов
- `app/server.py` — веб-сервис, мост к Gemini, инструменты `ask_hermes` и `get_hermes_task`
- `app/hermes.py` — очередь поручений с подтверждением и локальным журналом
- `web/` — интерфейс: `index.html`, `app.js`, `mic-worklet.js`
- `state/` — журнал поручений, `logs/` — журналы запуска

## Если что-то не так

- **Нет звука**: нажмите «Начать разговор» ещё раз, звук в браузере включается только по клику.
- **Микрофон не даёт доступ**: Системные настройки → Конфиденциальность → Микрофон → Chrome.
- **Показ экрана не стартует**: Системные настройки → Конфиденциальность → Запись экрана → Chrome,
  затем перезапустите Chrome.
- **Гермес «недоступен»**: проверьте, что на VPS включён его API-сервер и работает SSH-туннель.
- Журналы: `logs/vektor-live.log` и `logs/tunnel.log`.

## Остановка

Ctrl+C в окне Терминала или закрыть окно. Микрофон, показ экрана, туннель и сессия Google закрываются.
Автозапуск при входе в систему не настраивается.
