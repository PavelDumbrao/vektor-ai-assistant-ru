## Что изменить (обратная связь владельца продукта)
Человек должен СЛЫШАТЬ голоса до выбора. Сейчас он получает только кнопки с именами.

### 1. Примеры голосов при `/golos`
- Готовые образцы лежат в `/opt/vektor/voice-samples/` (root 0644, читаются всеми): `<voice_id>.ogg` (Ogg/Opus, формат голосовых Telegram) и `manifest.json`
  (`{"phrase": …, "voices": [{"index": 1, "label": "♂ Артём — подкаст", "voice_id": "...", "gender": "male", "file": "<voice_id>.ogg"}, …]}`).
  Константа `SAMPLES_DIR = Path("/opt/vektor/voice-samples")`; список голосов по-прежнему из константы `VOICES` в плагине (manifest — только для проверки наличия файлов).
- На `/golos` (и алиасы) плагин, ДО клавиатуры, отправляет в чат 10 голосовых сообщений через PTB-бота адаптера:
  `await bot.send_voice(chat_id=chat_id, voice=<открытый файл или bytes>, caption=f"{index}. {label}")` строго по порядку 1→10.
  Отправлять последовательно (не параллельно), с паузой ~0.3 с между сообщениями; на ошибке одного образца — логировать «sample send failed» (без ID) и продолжать.
  Если файла образца нет — пропустить его, а в подписи клавиатуры всё равно показать голос.
- Затем сообщение с reply-клавиатурой (как в v1), текст: «Послушай примеры выше и выбери голос кнопкой 👇».
- Если PTB-бот недоступен — fallback как в v1 (текстовый список), образцы не слать.

### 2. После выбора
- Записать `voice_id`/`model_id` в config.yaml (как в v1), убрать клавиатуру.
- Подтверждение — ТЕМ ЖЕ голосом: отправить образец выбранного голоса (`send_voice`) с подписью
  «Готово! Теперь я говорю голосом «<имя без эмодзи и пояснения>». Голосовые ответы включены: на голосовое отвечу голосом. Все ответы голосом — /voice tts, выключить — /voice off, сменить голос — /golos».
  (Имя: из label убрать символ пола и часть после « — ».)
- Автовключение голосового режима: вместо `{"action": "skip"}` вернуть из `pre_gateway_dispatch`
  `{"action": "rewrite", "text": "/voice on"}` — тогда шлюз выполнит команду `/voice on` для этого чата штатно
  (см. контракт хука в `hermes_cli/plugins.py`: `pre_gateway_dispatch` → skip/rewrite/allow; поле `text`).
  Проверь по коду `gateway/run.py` (поиск `_set_adapter_auto_tts_enabled`, `/voice on`), что rewrite с текстом команды действительно обрабатывается как команда; если rewrite команд не поддерживается — оставь `skip` и напиши это в отчёте с указанием места в коде.

### 3. Безопасность и прочее — без изменений v1
Только владелец/tech-admin, только ЛС, атомарная запись, TTL, state 0600, ничего не логировать кроме «voice changed»/«sample send failed».

### 4. Тесты (дополнить)
- `/golos`: отправлено ровно 10 `send_voice` в правильном порядке с подписями «N. label», затем клавиатура; отсутствующий файл пропускается; ошибка одного `send_voice` не прерывает остальные.
- Выбор: `send_voice` с образцом выбранного голоса и правильной подписью; возвращаемое значение хука `{"action": "rewrite", "text": "/voice on"}` (или `skip`, если выяснилось, что rewrite не поддержан — тогда тест на это).
- Старые тесты остаются зелёными (обнови те, что осознанно меняют контракт, перечисли в отчёте).
